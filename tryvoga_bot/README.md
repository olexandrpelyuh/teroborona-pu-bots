# Бот сповіщень про повітряні загрози

Перевіряє відкритий API mapa.ua (БпЛА/ракети з координатами та швидкістю)
і надсилає в Telegram-канал:
- 🚨 початок атаки (що летить, куди, скільки);
- ⚠️ наближення загрози до вашого міста з розрахунком «приліт через N хв»;
- 🚨 критичне попередження за ~15 хв до орієнтовного прильоту;
- ✅ зняття загрози з підсумком атаки.

## Крок 1. Бот і канал (як у боті графіків)
1. `@BotFather` → `/newbot` → скопіюй токен.
2. Додай бота адміністратором каналу з правом публікації.
3. ID каналу: `@nazva_kanalu` або `-100xxxxxxxxxx`.

## Крок 2. Визнач точку стеження
За замовчуванням — Південноукраїнськ (47.82, 31.18). Якщо інше місто —
задай координати в змінних (див. крок 3).

## Крок 3. Запуск

### Через GitHub Actions (безкоштовно)
1. Створи репозиторій, завантаж файли.
2. Settings → Secrets and variables → Actions → New repository secret:
   - `BOT_TOKEN` — токен з кроку 1
   - `CHANNEL_ID` — ID каналу
   - (необов'язково) `WATCH_LAT`, `WATCH_LON`, `WATCH_NAME` — точка стеження
   - (необов'язково) `WARN_ETA_MIN` (за замовч. 60), `CRITICAL_ETA_MIN` (15)
   - (необов'язково) `ALERTS_TOKEN` + `OBLAST_UID` — статус тривоги по області
     (токен безкоштовно: заповни форму на devs.alerts.in.ua)
3. Готово: перевірка кожні 5 хв.

### Локально/VPS (частіше, ніж раз на 5 хв)
```
pip install requests
BOT_TOKEN="..." CHANNEL_ID="@..." python bot.py --test
crontab -e
```
```
*/1 * * * * cd /шлях/до/tryvoga_bot && BOT_TOKEN="..." CHANNEL_ID="@..." python3 bot.py >> bot.log 2>&1
```

## Команда ручного звіту
```
python bot.py --now   # поточна обстановка в небі — надішле в канал
```

## Важливо
- Карта орієнтовна: бот рахує ETA за прямою і поточною швидкістю. За сигналом
  тривоги — одразу в укриття, не чекаючи на повідомлення.
- API mapa.ua — неофіційний/відкритий; якщо його структура зміниться,
  бот повідомить про помилку в логах (нічого страшного не станеться).
